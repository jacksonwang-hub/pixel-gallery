Key foundations: near-monochrome ink scale (color only from pixel photos), system Helvetica with tight-bold display + UPPERCASE tracked labels, the signature 1.5px black keyline frame with wide white mat, square corners, quiet shadows, restrained motion. All photographs render `image-rendering: pixelated`.
